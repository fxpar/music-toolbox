Rappels théorie musicale

Les formules d'accords expriment la distance (les intervalles) entre la Fondamentale (R) et les autres notes.

Symboles classiques

  • R : Root (Fondamentale)
  • b3 / 3 : Tierce mineure / majeure
  • b5 / 5 / #5 : Quinte dim / juste / aug
  • b7 / 7 / bb7 : Septième min / maj / diminuée
