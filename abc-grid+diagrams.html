Grille-To-ABC Editor
Configuration
Séparez par des espaces. Utilisez % pour répéter la mesure.

Syntaxe de base : NomAccord(DoigtéOptions)

  • C G Am : Séparer les accords avec des espaces: une mesure par accord.
  • C | G Am | C : Utilise | pour séparer TOUTES les mesures s'il y a plusieurs accords par mesure
  • C | % | G Am | % : Utilise % pour répéter la mesure précédente.
  • G7/D : les renversements n'étant pas dans la base de donnée, le diagramme correspond à la partie avant le / même si le nom complet est affiché.
  • C°, G7/D, Am?, ?? : Les symboles °, / et ? sont acceptés dans les noms (voir en dessous pour les doigtés fixes).
  • La transposition s'applique aux diagrammes cherché dans la bibliothèque d'accord. (cliquez sur le bouton à la fin du player pour transposer).
Options doigtés fixes :
() C(0003) : Les 4 chiffres représentent les cases des 4 cordes (ex: 0003).
, G7(10,11,12,10) : Utilisez des virgules pour les numéros de case > 9.
p Position : Numéro de la case de départ (défaut : 0). Ex: p3
b Barré : Cases du barré. Ex: b1111 ou b22
f Doigts : Doigts utilisés ou annotations (chiffres, R, b3...). Ex: f1234, f5,R,b3,6
s Sub : Texte/intervalle affiché sous le schéma. Ex: s7b,3,5,R
l Longueur : Nombre de cases affichées (défaut : 5). Ex: l6
c Calcul automatique : Convertit automatiquement les numéros de cases à partir de la position p. Ex: C(9,10,8,12p8c) → devient cases 2,3,1,5 en position 8.

Basic Syntax: ChordName(FingeringOptions)

  • C /// G // Am: Use / to repeat the measure.
  • C(0003): The 4 digits represent frets for the 4 strings (e.g., 0003).
  • G7(10,11,12,10): Use commas for fret numbers > 9.
  • C°, G7/D, Am?, ??: Symbols like °, / and ? are accepted in chord names.
Advanced Options (following the frets):
p Position: Starting fret position (default: 0). Ex: p3
b Barre: Barre frets. Ex: b1111 or b22
f Fingers: Finger numbers or annotations (digits, R, b3...). Ex: f1234, f5,R,b3,6
s Sub: Subtitle/intervals displayed below the diagram. Ex: s7b,3,5,R
l Length: Number of visible frets (default: 5). Ex: l6
c Calculate: Automatically calculates relative fret numbers based on position p. Ex: C(9,10,8,12p8c) → becomes frets 2,3,1,5 at position 8.
