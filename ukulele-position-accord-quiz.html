Transformer un accord

Comment jouer

  • Le manche est vu de face : les cordes G, C, E, A de gauche à droite, les cases de haut en bas.
  • L'accord de départ est affiché. La pastille rouge est la racine : elle ne bouge pas.
  • Touchez une case pour y déplacer la note de cette corde (une note par corde).
  • Toutes les notes de l'accord cible doivent être présentes, sans note étrangère, sur 5 cases au plus.
  • « Indice » affiche les formules ; « Correction » montre une forme possible (la question ne rapporte alors plus de points).
